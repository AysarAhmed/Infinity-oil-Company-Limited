HATUA ZA KUWEKA (dakika 10)

1) supabase.com > Sign up > New project (chagua region karibu, mfano Frankfurt). Subiri ikamilike.
2) SQL Editor > New query > paste yaliyomo ya supabase-setup.sql > Run.
3) Project Settings > API: nakili "Project URL" na "anon public key".
4) Fungua assets/js/reviews.js, badilisha mistari miwili juu (PASTE_...) kwa thamani hizo.
5) Upload kwenye hosting yako:
     index.html            -> badilisha ile ya zamani
     assets/css/reviews.css -> mpya
     assets/js/reviews.js   -> mpya
6) KUKUBALI MAONI: Supabase > Table Editor > reviews. Maoni mapya yanakuja na approved = false.
   Washa (tick) approved = true kwenye yale unayotaka yaonekane. Futa (delete) ya hovyo.
